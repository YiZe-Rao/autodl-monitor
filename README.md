# AutoDL 实例监控

用浏览器监控 AutoDL 容器 CPU / GPU 利用率，折线图展示，带登录。

- 后端：Python 3.12 + FastAPI + SQLite
- 采集：Playwright 驱动本机 Chrome，打开实例列表页，逐行抓取「第 5 列 div/div[2]」的利用率文本
- 前端：单页 ECharts 折线图（无构建步骤）
- 数据：本地 `data/monitor.db`，默认保留 7 天

## 快速开始

1. `install.bat`  — 首次安装依赖（本机已装好的话可跳过）
2. `start.bat`    — 启动面板，自动打开 http://127.0.0.1:8000

**登录**：在页面上直接输入 **AutoDL 手机号 + 密码**。

- 能静默登录时直接进入，无需其它操作；
- 如果 AutoDL 要求人机验证（滑块），会自动弹出一个登录窗口，把滑块拖完，本页面会自动进入；
- 登录成功后账密用 Windows DPAPI 加密存在本机（只有当前 Windows 用户能解密），
  会话过期时在页面上重新登录一次即可。

`login.bat` 仍保留为备用方式（不想在页面里填密码时，可以手动登录一次保存会话）。

## 监视范围

登录态下实例列表里的**全部实例**，每 15 秒刷新一次，每台实例一条曲线。

## 界面

- 顶部：采集状态、实例数、立即采集、原始数据、设置、退出
- 实例卡片：当前 CPU / GPU 值，点击可切换是否画在图上
- 时间范围：10 分钟 / 1 小时 / 6 小时 / 24 小时 / 7 天
- 两张图：CPU 利用率、GPU 利用率（多实例多线，悬停看数值）

## 数据来源（实测）

| 指标 | 来源 | 说明 |
|---|---|---|
| CPU / 内存 | 实例列表页第 5 列「健康状态」 | 形如 `正常 CPU 9% 内存 28%`，站点已把多核归一化到 0-100% |
| GPU 利用率 | 每台实例的「实例监控」(AutoPanel) | 接口 `/autopanel/v1/monitor`，取 `n.g[i].u`；该页必须从控制台点击进入才授权，程序按同样方式点击 |
| CPU（监控口径） | 同上 | `n.c / sys.lc × 100`，用于列表页取不到时兜底 |

> 注意：实例列表里**没有** GPU 利用率，只有 CPU 和内存；GPU 只能从实例监控页拿。
> 这也是为什么采集时每台运行中的实例会短暂打开一次监控页（约 2-4 秒）。

## 常见问题

**登录提示「手机号或密码不正确」**
这表示 AutoDL 拒绝了这组账密。请在 autodl.com 确认密码后重试。
面板本身不再有独立密码。

**弹出登录窗口但页面空白 / 滑块加载不出来**
旧版是因为上次的 Chrome 进程没退干净，占着 `data/login-profile` 配置目录，
新窗口会被 Chrome 判成“已在运行的会话”而直接退出。现在启动前会自动清理残留进程，
并在失败时给出提示（日志在 `data/login_child.log`）。

**图表没数据 / 提示“没解析到数据”**
点右上角「原始数据」，把弹窗内容发给助手。里面能看到表头、每行每列的实际文本。

**提示“需要重新登录 AutoDL”**
AutoDL 会话过期了（一般几天到几周）。重新运行 `login.bat`，在弹出的窗口里手动登录，
登录成功后按回车保存会话；不用重启面板，下一轮采集会自动恢复。

> **为什么不能自动登录**：AutoDL 的密码登录会弹「请完成安全验证」滑块，这是站点的人机校验。
> 程序不破解滑块、也不伪造指纹，只负责保存你**人工登录后**的会话。
> 这是唯一稳定且合规的方式。

**关于频率限制（防机器人）**
- 面板登录：同一 IP 10 分钟内失败 5 次即锁定，返回 429，提示等待时间。
- AutoDL 登录尝试（`tools/autodl_login_test.py`）：两次尝试至少间隔 5 分钟，
  每小时最多 3 次、每天最多 10 次，失败后指数退避（10 分钟 → 30 分钟 → 1 小时 → 2 小时，带随机抖动）。
  只有真正提交到登录接口的请求才计数，被前端校验拦下的不算。
- 采集端：会话失效后降到 **10 分钟**才探测一次，不会反复撞登录页。

**换端口 / 局域网访问**
改 `data/config.json` 里的 `app.host`（`127.0.0.1` → `0.0.0.0`）和 `app.port`，重启。

## 设计取舍

- **登录不硬破验证码**：只做“人工登录一次 → 保存 storage_state → 程序复用”，失效时提示重登。
- **不存 AutoDL 账号密码**：只存浏览器会话（cookies/localStorage），可随时删除 `data/storage_state.json`。
- **选择器配置化**：XPath 保存在配置里仅作记录，实际按“列号 + 单元格文本正则”解析，抗前端小改版。
- **容错**：单次采集失败不写脏数据，连续失败在状态栏标红；需要登录时降频到 60 秒重试。
- **注意**：自动化访问可能受站点规则约束，保持低频（默认 15 秒）并只用自己的账号。
